# Подготовка к Netlify

Это локальная заготовка, а не запущенная регистрация. Функция отвечает 503 при отсутствии DENMILY_AUTH_ENABLED=true. Не включайте её до проверок, перечисленных в ../denmily-auth-backend/README.md. В папке public только публичные ресурсы; ключи и настройки сервера нельзя туда помещать.

## Восстановление пароля сайта

Пользователь подтверждает владение игровым аккаунтом одноразовым кодом `/sitecode`, введённым после входа на Minecraft-сервер. Код привязан к UUID и нику, действует пять минут, принимается один раз. Пароль сайта можно сменить только для аккаунта с тем же UUID; после смены версия авторизации повышается и старые сессии становятся недействительны. Почта не участвует: владение ей сейчас не подтверждается.

Локальный сценарий проверяется командой `node auth-recovery.test.mjs`. Перед публикацией требуется пройти проверку условных записей на реальном Netlify Blobs и повторно проверить полный сценарий на опубликованном сайте. На 11.11.2026 production-публикации Netlify приостановлены из-за исчерпания кредитов команды.

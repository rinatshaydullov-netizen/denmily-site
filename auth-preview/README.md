# Подготовка к Netlify

Это локальная заготовка, а не запущенная регистрация. Функция отвечает 503 при отсутствии DENMILY_AUTH_ENABLED=true. Не включайте её до проверок, перечисленных в ../denmily-auth-backend/README.md. В папке public только публичные ресурсы; ключи и настройки сервера нельзя туда помещать.
